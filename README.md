# 오목 핵 ( OMOK CLIENT )

스마트폰 화면에 보이는 오목 바둑판을 **실시간으로 감지**해서, 다음에 둘 좋은 자리를 게임 화면 위에 표시해 주는 안드로이드 앱입니다.

## 설치 방법

1. 이 저장소의 **Releases → `latest`** 에서 `OmokHelper.apk` 를 휴대폰으로 다운로드합니다.
   (또는 **Actions** 탭 → 가장 최근 빌드 → `OmokHelper-apk` 다운로드 후 압축 해제)
2. 휴대폰에서 APK를 열어 설치합니다. "출처를 알 수 없는 앱" 설치 허용이 필요할 수 있습니다.

## 사용 방법

1. 앱에서 **판 크기(15/19)** 와 **규칙** 을 게임과 같게 고르고, **AI 생각 시간**(0.5/1.5/3초)을 정합니다.
2. **다른 앱 위에 표시** 권한을 허용합니다.
3. **화면 감지 시작** → 화면 녹화를 허용합니다.
4. 오목 게임을 열고, 떠 있는 패널의 **[판 맞추기]** 를 누릅니다.
5. 바둑판의 **맨 왼쪽 위 교차점**, **맨 오른쪽 아래 교차점** 을 차례로 맞추고 **[저장]** 합니다.
6. 이제 판이 바뀔 때마다 추천 자리에 고리가 나타납니다. (빨강 1순위 · 주황 2순위 · 파랑 3순위 이하)
   패널에는 좌표와 이유(예: `H8 4-3 공격 (필승)`), 필승 수순이 표시됩니다.

### 게임 중에 흑/백 바꾸기

패널 제목줄의 **`나: 자동 ⇄`** 칩을 누를 때마다 **자동 → 흑 → 백** 순서로 바뀝니다. ([설정]의 "내 돌"에서도 고를 수 있어요)

- **자동** : 지금 차례인 쪽의 추천을 보여 줍니다.
- **흑 / 백** : 내 차례일 때만 추천을 보여 주고, 상대 차례에는 "상대 차례 — 기다리는 중"으로 표시합니다.

### 패널의 [설정]

| 항목 | 설명 |
|---|---|
| 내 돌 | 자동 / 흑 / 백 |
| 판 프리셋 | `[저장 1~3]` : 지금 바둑판 위치와 크기(15/19줄)를 저장 · `[1~3]` : 저장한 위치를 바로 불러오기. 게임이나 화면 배치마다 저장해 두면 [판 맞추기]를 다시 할 필요가 없습니다 |
| 표시 크기 | 작게 / 보통 / 크게 — 추천 고리와 패널 글자 크기 |
| 인식 결과 보기 | 켜면 앱이 읽은 돌(흑 = 하늘색 점, 백 = 분홍 점)과 금수 자리(빨간 ×)를 교차점 모서리에 작게 표시. 인식이 맞는지 확인할 때 사용 |
| 흑 차례 색 / 백 차례 색 | 흑 차례 추천과 백 차례 추천의 고리 색을 따로 고름 (기본 · 네온 · 파스텔 · 고대비 · 흑백). 자동 모드에서 어느 쪽 추천인지 색으로 바로 구분되고, 패널 첫 줄에도 그 색 점(●)이 붙음 |
| 패널 색 | 다크 · 라이트 · 네이비 · 우드 · 반투명 (누를 때마다 다음 색) |

표시 크기를 바꿔도 추천 고리는 돌 인식에 쓰는 교차점 한가운데를 가리지 않도록 설계했고, 모든 색·크기 조합에서 고리가 돌로 잘못 인식되지 않는지 테스트로 확인합니다.

## 🔑 키 (라이선스)

키가 없어도 앱을 쓸 수 있지만, 아래 기능은 **키를 등록해야** 열립니다.

| 기능 | 키 없음 | 키 등록 |
|---|---|---|
| 내 돌 선택 | 자동만 | 자동 / 흑 / 백 |
| 추천 개수 | 1개, 3개 | 1개, 3개, **5개** |
| AI 생각 시간 | 0.5초, 1.5초 | 0.5초, 1.5초, **3초** |

**등록 방법** : 앱 첫 화면의 "🔑 키" 칸에 받은 키(`OMOK1-`로 시작)를 붙여 넣고 [키 등록]. 키 문의 : Discord `axkoth`

**원리 (전자서명)** — `LicenseKey.java`
- 키를 만드는 사람은 **비밀 키**로 키 내용(키 번호, 만료일)에 ECDSA P-256 서명을 합니다.
- 앱에는 **공개 키**만 들어 있어서 서명이 맞는지 확인만 할 수 있고, 새 키를 만들 수는 없습니다.
- 키 내용을 한 글자라도 바꾸면 서명이 맞지 않아 거부됩니다. 서버 없이 인터넷 연결 없이 동작합니다.

**키 발급 (저작권자 전용)** — `tools/KeyGen.java`
```bash
java KeyGen.java make 7               # 7번 키 (무기한)
java KeyGen.java make 8 2027-03-01    # 8번 키, 2027-03-01까지
java KeyGen.java make 10 20           # 10~20번 키 여러 개
```
비밀 키 파일 `omok-private.key`가 같은 폴더에 있어야 하며, 이 파일은 `.gitignore`로 저장소에 올라가지 않게 막혀 있습니다.

## 동작 원리

```
화면 인식 ──▶ 바둑판 인식 ──▶ 수 분석 ──▶ 오버레이 표시
(0.6초마다)   (색상 판별)     (패턴+탐색)   (추천 고리)
```

### 1. 화면 캡처 — `CaptureService.java`
안드로이드의 `MediaProjection` API로 화면을 0.6초마다 이미지로 받아 옵니다.
같은 판이 두 번 연속 읽혀야 확정해서, 돌이 놓이는 애니메이션 중간 화면은 무시합니다.

### 2. 바둑판 인식 — `BoardDetector.java`
- 사용자가 맞춘 두 모서리 좌표로 15×15(또는 19×19)개 교차점의 위치를 계산합니다.
- 각 교차점 주변 작은 원 안 픽셀들의 **밝기·채도 중앙값**을 구합니다. (중앙값을 쓰면 선이나 마지막 수 표시에 덜 흔들립니다)
- 돌로 인정하려면 교차점 한가운데뿐 아니라 **바깥 고리(반지름 0.34칸)** 도 같은 색이어야 합니다. 게임이 금수 자리·미리보기에 그리는 작은 점, ×, 반투명 돌은 돌로 읽지 않습니다.
- 칸 한가운데에서 잰 **바둑판 색**과 비교해서
  - 훨씬 어둡고 무채색이면 → 흑돌 (빨간 표시 등 색이 있으면 제외)
  - 밝고 무채색이면 → 백돌
  - 그 외 → 빈칸
